# Images Folder

This folder contains image assets for the portfolio website.

## Recommended Images

1. **Profile Photo**: Professional headshot (optional)
2. **Project Screenshots**: Screenshots of your projects
3. **Favicon**: Small icon for browser tab
4. **Background Images**: Any custom background images

## Image Guidelines

### File Formats
- **Photos**: JPG or WebP
- **Graphics/Icons**: PNG or SVG
- **Favicon**: ICO or PNG

### Optimization
- Compress images for web use
- Use appropriate dimensions
- Consider using WebP format for better compression

### Naming Convention
- Use descriptive names
- Use lowercase letters
- Separate words with hyphens
- Include dimensions if multiple sizes

Examples:
- `profile-photo-400x400.jpg`
- `project-ai-code-reviewer-screenshot.png`
- `favicon-32x32.ico`

## Current Implementation

The website currently uses:
- Font Awesome icons for most graphics
- CSS gradients for backgrounds
- No custom images (fully functional without additional images)

## Adding Custom Images

1. Place images in this folder
2. Update the HTML `src` attributes
3. Add appropriate `alt` text for accessibility
4. Consider adding lazy loading for performance

## Favicon Setup

To add a custom favicon:
1. Create a 32x32 pixel icon
2. Save as `favicon.ico`
3. The HTML already includes the favicon link
