# Katukoori Nithin - Portfolio Website

A modern, responsive portfolio website showcasing DevOps engineering and data science expertise.

## Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern Animations**: Smooth transitions, hover effects, and scroll animations
- **Interactive Elements**: Dynamic navigation, typing animations, and particle effects
- **Professional Layout**: Clean, modern design with dark theme and blue accents
- **Performance Optimized**: Fast loading with optimized assets

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid, Flexbox, and CSS animations)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Inter)

## Project Structure

```
portfolio-website/
├── index.html              # Main HTML file
├── css/
│   └── styles.css          # Main stylesheet
├── js/
│   └── script.js           # JavaScript functionality
├── assets/
│   └── images/             # Image assets
├── docs/                   # Documents (resume, etc.)
└── README.md              # Project documentation
```

## Sections

1. **Hero Section**: Introduction with animated typing effect
2. **About**: Professional summary and statistics
3. **Skills**: Technical skills organized by category
4. **Projects**: Featured projects with descriptions and links
5. **Experience**: Professional timeline
6. **Education**: Academic background
7. **Certifications**: Professional credentials
8. **Contact**: Contact information and social links

## Setup Instructions

1. Download or clone the portfolio-website folder
2. Open `index.html` in a web browser
3. For development, use a local server (e.g., Live Server extension in VS Code)

## Customization

### Colors
The main color scheme uses:
- Primary: #0E5484 (Blue)
- Secondary: #0099CC (Light Blue)
- Background: #0a0a0a (Dark)
- Text: #ffffff (White)

### Content Updates
- Update personal information in `index.html`
- Modify project details in the projects section
- Add/remove skills in the skills section
- Update social media links

### Adding New Sections
1. Add HTML structure in `index.html`
2. Add corresponding styles in `css/styles.css`
3. Add navigation link if needed
